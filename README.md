# Inventory Management System

This is my first university project, developed using **Java** and **JavaFX**.

The Inventory Management System is a simple desktop application designed to manage inventory items and their details through an interactive graphical user interface.

## Features

- Add new inventory items
- Store Item ID, Name, Quantity, and Price
- Update item quantities
- Calculate the total inventory value
- Detect low-stock items
- Automatically load inventory data
- Display inventory details and operation results
- User-friendly graphical interface
- Custom font integration

## Inventory Information

Each inventory item contains:

- **ID** – Unique identification number of the item
- **Name** – Name of the inventory item
- **Quantity** – Number of items available
- **Price** – Cost of the item
- **Items** – Displays the inventory information

## Available Operations

### Add Item +

Allows the user to add a new inventory item by entering its ID, name, quantity, and price.

### Update Quantity

Allows the user to update the quantity of an existing inventory item.

### Total Value

Calculates and displays the total value of the inventory.

### Low Stock

Allows the user to identify items that have a low quantity in stock.

### Auto Load

Automatically loads the available inventory data into the application.

## Results Display

The application contains a dedicated results area below the operation buttons.

After performing an operation, the relevant message or inventory information is displayed in this area so that the user can easily see the result of the selected operation.

## How to Run

### Requirements

Before running the project, make sure you have:

- **Java JDK** installed
- **JavaFX SDK 21.0.5** installed
- **IntelliJ IDEA** installed
- JavaFX properly configured in IntelliJ IDEA

### Running the Project

1. Download or clone this repository from GitHub.
2. Open **IntelliJ IDEA**.
3. Open the downloaded project.
4. Make sure the **JavaFX SDK 21.0.5** is available.
5. Configure the JavaFX SDK and required JavaFX libraries.
6. Open `Project.java` from the `src` folder.
7. Run the JavaFX application.

### JavaFX Configuration

The project uses JavaFX for the graphical user interface.

Make sure the JavaFX SDK is correctly configured in IntelliJ IDEA before running the application.

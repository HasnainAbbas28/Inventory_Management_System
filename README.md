# Inventory Management System

This is my first university project, developed using Java and JavaFX.

The Inventory Management System is a simple application designed to manage
inventory items and their details through an interactive graphical interface.

## Features

- Add new inventory items
- Store Item ID, Name, Quantity, and Price
- Update item quantities
- Calculate the total inventory value
- Check for low-stock items
- Automatically load sample inventory data
- Display inventory details and operation results
- User-friendly JavaFX graphical interface

## Project Structure

The application provides input fields for:

- ID
- Name
- Quantity
- Price
- Items

It also includes the following operations:

- **Add Item** — adds a new inventory item
- **Update Quantity** — changes the quantity of an existing item
- **Total Value** — calculates the total value of the inventory
- **Low Stock** — identifies items with low stock
- **Auto Load** — loads sample inventory data automatically

The lower display area is used to show inventory information and messages
based on the selected operation.
